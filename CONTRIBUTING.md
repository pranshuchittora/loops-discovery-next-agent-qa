# Contributing

Thanks for helping grow Awesome Agent Loops!

## Adding a resource

- One line per entry: `- [Name](link) - One-sentence description ending with a period.`
- Put it in the section that fits; suggest a new section in the PR description if none does.
- Link to the original source (author's post, repo, or docs), not an aggregator.
- Check for duplicates before adding.
- Descriptions say what the thing does, not how awesome it is.
- Self-promotion is allowed if the resource is genuinely useful and runnable — just say it's yours in the PR.

## Adding a loop pattern

Describe it in the seven-field shape: goal, trigger, discover, act, verify, persist, exit. If you have measured token cost per cycle, include it.

## Style

- Run `npx awesome-lint` before submitting.
- Sentence case; descriptions end with a period.

## Quality bar

Working beats popular. If a loop can't be run or verified, it doesn't belong here.
